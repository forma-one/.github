# Форма

Тренировки по готовым программам: дневник подходов, прогресс и лента друзей.

Тренировку можно пройти целиком без сети, собрать свою программу из каталога упражнений
и следить за прогрессом друзей. Есть приложение для iOS и Android и сайт.

- Сайт — [forma-one.ru](https://forma-one.ru/)
- Сообщество — [t.me/forma_one_chat](https://t.me/forma_one_chat)
